# 志明哥做的｜朋友生日魔法小站（資料庫版）

這是志明哥做的 RWD 單頁網站，手機、平板、電腦都能用。

## 資料庫
- 資料庫就是志明哥自己的 Google 試算表「朋友生日名單」，由 Apps Script 當寫入／讀取接口。
- 試算表網址由志明哥保管，網站程式碼裡只放 Apps Script 的網路應用程式網址（`config.js`）。
- 試算表欄位：填寫時間、姓名、稱呼、生日月、生日日、出生年份、共同單位社團、其他、留言。

## 公開頁（給朋友）：index.html
1. 打開網站，填姓名、生日月日（年份可不填）。
2. 勾選你和志明哥是在哪些單位／社團認識的，也可以自己補寫其他單位。
3. 按送出，就會看到你的星座、生肖、生命靈數、個性描述和今天適合做的事，同時資料會寫進志明哥的試算表。
4. 如果送出時網路有問題，頁面會明確說送出失敗，請改按「複製給志明哥」傳給他，不會讓人以為成功卻沒進表。
5. **公開頁沒有名單**：不會顯示別人的生日。

## 後台（只有志明哥）：admin.html
- 後台連結請不要公開貼出，公開頁面也沒有連到後台。
- 第一次開後台要先設一個後台密碼，之後開後台都要輸入；關掉分頁後要重新輸入。
- 後台有「資料庫名單」區：按「從資料庫重新載入」就能看到朋友填完的全部資料、照生日快到慢排，也能從資料庫刪除、匯出 CSV。
- 後台也保留本機模式：志明哥手動新增、文字匯入、JSON 匯入、本地匯出，方便補登朋友傳來的文字。
- 今日壽星以資料庫名單為準（按重新載入後），本機名單區另外顯示。

## 保密說明
- 朋友在自己手機上打開公開頁或後台，都看不到志明哥試算表裡的全部資料；後台資料庫區需要後台密碼先解鎖，讀取時還要網站設定裡的接口驗證。
- 真正要注意的是同一支手機：如果志明哥把解鎖後的手機借給別人，別人就可能在後台看到名單。所以用完請按「鎖定後台」，也不要把後台連結公開貼出。
- 網站程式碼裡的接口驗證碼只能擋住隨手亂填的人，懂技術的人還是能從網頁原始碼看到它，所以不要把生日名單當成高度機密資料來用；後台密碼鎖也是本機簡易鎖，不是銀行等級的帳號系統。

## 防詐騙聲明（網站首頁也有大字提醒）
本站只收姓名、生日、共同單位／社團。
絕對不會要密碼、身分證字號、銀行帳號、驗證碼，也不會叫人轉帳或點奇怪連結。
冒用志明哥名義要這些資料的，就是詐騙。

## 技術說明
- `index.html`（公開頁）、`admin.html`（後台）、`config.js`（資料庫網址設定）、`README.md`，無外部資源。
- `Code.gs` 是 Apps Script 程式碼，只放在試算表綁定的 Apps Script 專案裡，不放進公開儲存庫。
- 星座、生肖、生命靈數與「今天適合」皆為輕鬆趣味的參考，不是命理預測。
