# 志明哥做的｜朋友生日魔法小站

這是志明哥做的 RWD 單頁網站，手機、平板、電腦都能用。

## 給朋友：怎麼填
1. 打開網站，填姓名、生日月日（年份可不填）。
2. 勾選你和志明哥是在哪些單位／社團認識的，也可以自己補寫其他單位。
3. 按「儲存」，就會看到你的星座、生肖、生命靈數、個性描述和今天適合做的事。
4. 按「複製給志明哥」，用 LINE 或 Facebook 傳給志明哥，志明哥就能記住你的生日。

## 給志明哥：怎麼收
- 朋友在自己手機上填的資料，**不會自動跑到志明哥手機**，因為本站沒有伺服器、資料只存在填寫的那支裝置。
- 朋友傳來的文字請先留著；若朋友傳來 JSON 備份，貼到網站「志明哥匯入」區就能集中成名冊。
- 名單照「生日快到慢」排序，今天有壽星會特別顯示在「今天的壽星」區。
- 匯出 CSV 可以整理、備份；刪除前建議先匯出。

## 防詐騙聲明（網站首頁也有大字提醒）
本站只收姓名、生日、共同單位／社團。
絕對不會要密碼、身分證字號、銀行帳號、驗證碼，也不會叫人轉帳或點奇怪連結。
冒用志明哥名義要這些資料的，就是詐騙。

## 技術說明
- 單一 `index.html`，無外部資源、無後端，資料只用瀏覽器 localStorage 儲存。
- 星座、生肖、生命靈數與「今天適合」皆為輕鬆趣味的參考，不是命理預測。
