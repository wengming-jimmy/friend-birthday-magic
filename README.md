# 志明哥做的｜朋友生日魔法小站

這是志明哥做的 RWD 單頁網站，手機、平板、電腦都能用。

## 公開頁（給朋友）：index.html
1. 打開網站，填姓名、生日月日（年份可不填）。
2. 勾選你和志明哥是在哪些單位／社團認識的，也可以自己補寫其他單位。
3. 按送出，就會看到你的星座、生肖、生命靈數、個性描述和今天適合做的事。
4. 按「複製給志明哥」，用 LINE 或 Facebook 傳給志明哥，志明哥就能記住你的生日。
5. **公開頁沒有名單**：不會顯示別人的生日，填的資料也不會留在公開頁給下一個人看。

## 後台（只有志明哥）：admin.html
- 後台連結請不要公開貼出，公開頁面也沒有連到後台。
- 第一次開後台要先設一個後台密碼，之後開後台都要輸入；關掉分頁後要重新輸入。
- 後台有：今日壽星、照生日快到慢排的名單、搜尋、刪除、匯出 CSV／JSON。
- 朋友用 LINE 傳來的那段文字，可以直接貼到後台「文字匯入」區，不用重打；也可以匯入 JSON 備份。

## 保密說明（請老實講給朋友聽也沒關係）
- 本站沒有伺服器，資料只存在填寫／匯入的那支裝置的瀏覽器裡，不會自動同步給別人。
- 所以：別人在自己手機上打開公開頁或後台，都只會看到自己那支手機的資料，看不到志明哥的名單。
- 真正要注意的是同一支手機：如果志明哥把解鎖後的手機借給別人填，別人就可能在後台看到名單。所以後台有密碼鎖，用完請按「鎖定後台」，也不要把後台連結公開貼出。
- 這個密碼鎖是簡易鎖，不是銀行等級的帳號系統；懂技術的人還是有辦法從瀏覽器裡翻到資料，所以不要把手機長期借人。

## 防詐騙聲明（網站首頁也有大字提醒）
本站只收姓名、生日、共同單位／社團。
絕對不會要密碼、身分證字號、銀行帳號、驗證碼，也不會叫人轉帳或點奇怪連結。
冒用志明哥名義要這些資料的，就是詐騙。

## 技術說明
- `index.html`（公開頁）、`admin.html`（後台）、`README.md`，無外部資源、無後端。
- 星座、生肖、生命靈數與「今天適合」皆為輕鬆趣味的參考，不是命理預測。
